# 진동 센서 FFT 주파수 기반 이상 탐지 보고서 (운영 제안)

작성일: 2026-02-02

본 문서는 **진동 센서 데이터를 FFT(주파수 분석)** 기반으로 이상 탐지하는 방법을 보고서 형식으로 정리한 것이다. 현재 운영은 속도 magnitude(p99) 기준이지만, 주파수 기반 판단은 회전계/기계 결함 진단에 유리하므로 **운영 개선안**으로 제안한다.

---

## 1) 배경 및 목적

- 현재 운영: 속도(velocity magnitude) 기반 임계치 판정
- 문제점: 속도 크기만으로는 **진동 패턴 변화**를 충분히 설명하기 어려움
- 개선 방향: **FFT 주파수 스펙트럼**을 활용해 특정 이상 주파수 대역을 탐지

---

## 2) FFT 기반 이상 탐지 개념

### 2.1 FFT란?
- 진동 데이터를 시간 영역(Time domain)에서 **주파수 영역(Frequency domain)**으로 변환
- 특정 주파수 대역에서 에너지가 급격히 증가하면 **이상 진동 신호**로 해석 가능

### 2.2 주파수 기반 장점
- 베어링 손상, 불균형, 공진 등 **특정 패턴**을 탐지 가능
- 속도 magnitude만으로는 놓칠 수 있는 **비정상 주파수 피크**를 직접 확인 가능

---

## 3) 데이터 처리 흐름 (제안)

1. **센서 데이터 수집** (X/Y/Z 축)
2. **윈도우 구간 설정** (예: 5초)
3. **FFT 계산**
4. **주파수 대역별 에너지 계산**
5. **이상 대역 감지** (threshold 또는 baseline 비교)

---

## 4) 이상 판단 기준 (주파수)

### 4.1 임계값 기준 방식
- 특정 주파수 대역의 에너지 또는 피크 값이 임계치 초과 시 이상
- 예: 50~70 Hz 또는 120~150 Hz 구간 (기계 고유 진동 대역)

### 4.2 베이스라인 대비 방식
- 정상 상태의 FFT 통계를 저장
- **baseline + kσ**를 초과하는 경우 이상 판단

---

```json
    {"min": 50, "max": 70},

  ]

```

---

## 6) 적용 시 기대 효과

- 진동 **패턴 기반 진단** 가능
- 동일 magnitude라도 **주파수 변화**를 감지 가능
- 오탐 감소 및 이상 원인 분석에 유리

---

## 7) 운영 적용 시 고려사항

- 장비별 정상 주파수 범위를 확보해야 함
- 환경 변화에 따라 주파수 피크가 이동 가능
- 초기에는 **모니터링/알림용**으로 운영 후 안정화 필요

---

## 8) 권장 운영 전략

1. 현재 속도 magnitude 기준을 유지
2. 병렬로 FFT 기반 모니터링을 추가
3. 일정 기간 데이터 축적 후 임계값 보정
4. 검증 완료 시 FFT 기반 이상 판단을 1차 또는 2차 판정으로 적용

---

## 9) 결론

FFT 주파수 기반 이상 탐지는 진동의 **원인 분석 및 조기 진단**에 유리하다. 현재 운영 중인 속도 임계치 방식은 유지하되, **FFT 기반 규칙을 병행**하면 더 높은 신뢰도의 이상 탐지가 가능하다. 초기에는 보조 지표로 적용하고, 데이터를 충분히 축적한 후 본 판정에 활용하는 것을 권장한다.
