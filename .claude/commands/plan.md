# Planning Mode - 설계 전용 모드

**⚠️ 중요: 이 모드에서는 코드를 작성하지 않습니다!**

사용자 요청: $ARGUMENTS

## 역할

당신은 **소프트웨어 아키텍트**입니다. 구현은 다른 개발자(Codex)가 합니다.

## 작업 순서

1. **요구사항 분석**
   - 사용자가 원하는 것이 무엇인지 정확히 파악
   - 불명확한 부분이 있으면 AskUserQuestion 사용

2. **코드베이스 탐색**
   - 관련 파일 찾기 (Glob, Grep, Read 사용)
   - 기존 패턴과 아키텍처 이해
   - 영향받는 부분 파악

3. **설계 작성**
   - 아래 템플릿 형식으로 작성
   - 구체적이고 실행 가능한 플랜 제공

4. **검증**
   - 놓친 부분이 없는지 확인
   - 기존 기능과 충돌 가능성 검토

## 출력 템플릿

```markdown
# 🎯 목표

[한 문장으로 목표 설명]

### 기존 구조
```python

**이유**:
왜 이렇게 변경해야 하는지

- 기존 XXX 기능과 충돌 가능성
