## 1. 보고 목적

본 보고서는 **조리 완료 AI의 1차 실증 결과**를 정리한 문서이며, 목표는 다음과 같다.

1. 현장 운용 관점에서 조리 완료 이벤트를 안정적으로 검출하는지 확인
2. 바스켓 감지 및 상태 추론이 운영 흐름에서 유효한지 점검
3. 보고/감사 대응을 위한 로그 및 이미지 근거 체계를 명확히 제시

본 문서는 정확도 벤치마크(F1/MAE)보다는, 현장 운영에서의 동작 신뢰성/적합성을 수치화한 **운영 적합도 검증 결과** 중심으로 작성한다.

- **완료 시점 = 바스켓이 기름 밖으로 완전히 이탈한 시점(꺼내는 시점)**

이 기준을 택한 이유:

3. 운영 자동화(알림/저장 종료/상태전환) 트리거로 직접 사용 가능

## 3. 평가 방법(운영 적합도)

## 3.1 지표 정의

본 실증에서 사용한 핵심 지표는 아래와 같다.

1. 완료 이벤트 검출률(%)
   - 정의: AI가 완료 이벤트를 감지한 세션 비율
   - 식: `(completion_detected=True 세션 수 / 전체 세션 수) × 100`

2. 완료 규칙 통과율(%)
   - 정의: 사전 정의한 완료 규칙(상태/이벤트 흐름)을 만족한 세션 비율
   - 식: `(규칙 통과 세션 수 / 전체 세션 수) × 100`

3. 운영 적합도 점수(0~100)
   - 정의: 검출 여부, 이벤트 일관성, 규칙 만족도를 종합한 운영 점수
   - 세션별 점수를 평균하여 전체 적합도 제시

4. 포트별 평균 적합도
   - 정의: `pot1`, `pot2` 별 운영 적합도 평균
   - 목적: 라인별 편차 확인 및 장애 진단 근거 확보

### 3.2 중요한 해석 원칙

- 본 수치는 **정답 라벨 기반 정확도(F1/MAE)**가 아니다.
- 본 수치는 **운영 적합도(실동작성/일관성/검출 안정성)**를 보여준다.

2. 규칙 통과율(79.4%)은 감지 이후의 상태/흐름 일관성 개선 여지가 있음을 의미
3. 포트별 편차(약 3.56점)는 라인 상태 차이 또는 입력 품질 차이를 시사

## 5. 정확도(F1/MAE)와의 관계

본 데이터에서 아래 항목이 관측되었다.

- `session_info.completion_marked=True` 관측 0건

의미:

1. 현장 수동 완료 라벨(정답 시점)이 저장되지 않아
2. 정답 대비 오차형 지표(F1, MAE)를 즉시 계산할 수 없음

따라서 본 보고서는 다음 원칙을 따른다.

- 1차 제출: 운영 적합도 실증 결과 제출
- 2차 제출: 라벨 확정 후 F1/MAE 별도 제출

이는 미측정이 아니라 **평가 단계 분리**다.

## 6. 보고서 본문에 반드시 넣어야 할 이미지 구성

아래 이미지를 넣으면 “수치 + 시각 근거”가 동시에 성립해 설득력이 올라간다.

## 6.1 필수 이미지 세트 (권장 12장)

1. 완료 이벤트 성공 사례 2세션 (각 2장, 총 4장)
   - 장면 A: 완료 직전(기름 잠김/상승 시작)
   - 장면 B: 완료 시점(바스켓 완전 이탈)
   - 출처: `reports/2026-02-15/images/lift_event_images_all`

2. 완료 이벤트 실패 사례 2세션 (각 2장, 총 4장)
   - 장면 A: 오검출/미검출 직전
   - 장면 B: 실제 완료 시점 근접 프레임
   - 목적: 실패 원인 설명(가림/조명/링크 불안정/경계 프레임)

3. 바스켓 감지 시각화 성공/실패 비교 (4장)
   - 성공 2장: 마스크/분류 결과가 안정적으로 일치
   - 실패 2장: 불안정 프레임 또는 잘못된 클래스
   - 출처: `reports/2026-02-15/images/bucket_vis_all`

## 6.2 이미지 캡션 형식(통일 권장)

각 이미지 캡션은 아래 4요소를 포함한다.

1. 세션 ID
2. 시점(상대 시간 또는 프레임 번호)
3. AI 판정(예: DETECT/FILLED, completion_detected)
4. 해석(정상/경계/실패 원인)

예시:

- `Session A, t=+12.4s, completion_detected=True: 바스켓 이탈 시점에서 완료 이벤트 정상 검출`
- `Session B, frame=183, cls=filled: 조명 반사 구간에서 분류 신뢰도 불안정`

## 6.3 본문 배치 순서

1. 결과 요약표 바로 아래: 성공 사례 이미지 2장
2. 실패 분석 섹션: 실패 사례 이미지 4장
3. 부록: 전체 이미지 인덱스 표(파일명, 세션, 라벨, 코멘트)

## 8. 리스크 및 한계

1. 일부 구간에서 카메라 링크 초기화 불안정 가능성

3. 현 단계 지표는 운영 적합도 중심이므로 모델 절대성능(F1/MAE)과 직접 동일시하면 안 됨
