| 항목 | 상태 | 비고 |

| 하드웨어 연결 | ✅ | WitMotion JY901B + CH340 USB-RS485 |
| 통신 프로토콜 | ✅ | Modbus RTU (pymodbus 3.x) |

| 시스템 통합 | ✅ | MQTT 연동 측정 자동화 |
| 이상 감지 알고리즘 | ✅ | 3-sigma / P99 기준 적용 |

- **측정 방식**: MQTT 요청 시 10초간 측정
- **출력 파일**: `vibration_result.json`
- **임계값**: velocity_magnitude P99 = 23,929 mm/s
