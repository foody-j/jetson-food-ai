# 조리완료 평가 지표 가이드 (기관 보고용)

작성 목적:
- "조리완료를 어떻게 수치화해서 보고할지"를 팀/기관 기준으로 정리
- 현장 대화에서 자주 나오는 오해(예: 들어올린 순간 vs 잠긴 순간 비교)를 방지

---

## 1. 왜 "들어올린 순간 vs 잠긴 순간 정확도 비교"가 욕먹었는가

핵심 이유는 **문제 정의가 다르기 때문**입니다.

- 들어올린 순간(탈탈)은 "행동 이벤트"입니다.
- 조리완료는 "품질 상태 이벤트"입니다.

즉,
- 모델 A: `들어올림 감지 정확도`
- 모델 B: `완료 판정 정확도`
를 같은 잣대로 비교하면, 기술적으로 질문이 성립하지 않는다고 받아들여질 수 있습니다.

기관/책임자 관점에서 원하는 것은 보통 아래 2개입니다.

1. 완료를 얼마나 맞게 판정했는가? (정확도)
2. 왜 완료라고 판단했는가? (설명 가능성)

---

## 2. 권장 구조: "완료 적합도 점수" + "완료 판정 정확도"

기관 보고는 보통 아래 2축이 가장 설득력 있습니다.

1. **실시간 운용 점수**: 완료 적합도 점수(0~100)
2. **검증 성능 지표**: Precision/Recall/F1 + 완료시점 오차(초)

---

## 3. 완료 적합도 점수(운영용)

### 3.1 점수식

\[
S = 100 \times (w_t T + w_c C + w_l L + w_p P)
\]

각 항목:
- \(T = \min(\frac{running\_time}{target\_time}, 1)\)
- \(C = \min(\frac{color\_delta}{color\_threshold}, 1)\)
- \(L = \min(\frac{lift\_count}{expected\_lift}, 1)\)
- \(P = \min(\frac{probe\_temp}{target\_temp}, 1)\)  (탐침 없으면 제외)

권장 가중치(초기):
- \(w_t=0.35, w_c=0.35, w_l=0.20, w_p=0.10\)

탐침이 없으면:
- \(w_t=0.40, w_c=0.40, w_l=0.20\)

### 3.2 완료 판정 규칙(예시)

- `S >= 85`
- AND `T >= 0.9`
- AND `C >= 0.8`

위 조건을 만족하면 "완료"로 판정.

---

## 4. 완료 판정 정확도(검증용)

라벨 데이터(사람이 찍은 실제 완료 시점)를 기준으로 아래를 계산:

- Precision
- Recall
- F1-score
- 완료시점 오차 MAE(초)

권장 보고 문구:
- "검증셋 N세션 기준 완료 판정 F1=0.xx, 완료시점 MAE=xx초"

---

## 5. 라벨링 정의(반드시 먼저 합의)

정확도 싸움의 80%는 라벨 정의에서 끝납니다. 먼저 합의해야 할 항목:

1. "완료" 기준
- 색상 기준인지, 내부온도 기준인지, 조리사 버튼 기준인지

2. 완료 시점 기준
- 첫 완료 프레임인지
- 3초 연속 완료 조건인지

3. 제외 조건
- 청소 모드
- 카메라 가림/결측 프레임

이걸 안 맞추면 모델이 좋아도 항상 분쟁이 납니다.

---

## 6. 책임자와 대화할 때 권장 표현

나쁜 표현(오해 유발):
- "들어올린 순간하고 잠긴 순간 정확도 비교해볼까요?"

좋은 표현(기관형):
- "들어올림은 보조 이벤트로 쓰고, 완료는 품질 상태로 분리해 평가하겠습니다."
- "완료 지표는 F1과 완료시점 MAE로 보고, 운영용으로는 적합도 점수 0~100을 제공하겠습니다."
- "라벨 정의(완료 기준/시점)를 먼저 합의한 뒤 평가하겠습니다."

---

## 7. 현재 Jetson 데이터에 바로 적용하는 순서

1. 세션별 `*_lift_events.json` 확인
- `lift_count`, `color_delta`, `running_time` 확보

2. 메타/세션 정보에서 `target_time`, `probe_temp` 확보

3. 세션별 `S` 계산
- 엑셀/파이썬 둘 다 가능

4. 라벨 파일(실제 완료시각)과 조인
- 세션 ID 기준

5. F1, MAE 계산 후 보고서 생성

---

## 8. 최소 제출안 (시간 없을 때)

아래 3개만 제출해도 기관 대응이 됩니다.

1. 완료 적합도 점수 정의식 (위 식)
2. 완료 판정 기준 (`S>=85` 등)
3. 검증 성능 2개 (F1, MAE)

---

## 9. 결론

- "탈탈 감지 정확도"와 "조리완료 정확도"는 분리해서 다뤄야 합니다.
- 기관 보고는 "점수(운영)" + "정확도(검증)" 2축이 가장 안전합니다.
- 대화의 초점은 이벤트 감지가 아니라 **완료 판정의 재현성과 설명 가능성**에 둬야 합니다.
